# ADR-0001 现流明细取数以"流量金额+现流项目"为权威，借贷列降级为回退

现流明细类表格的现金方向与金额，一律以"现流项目（项目名定方向）+ 流量金额（符号表红冲）"为权威来源；借贷列/方向列只在项目名无法识别方向时回退使用。

原因：真实文件实测证明，对方科目侧明细表中借贷列金额可能含非现金部分（清平 38 行借贷金额≠流量金额，如贴现息），借贷方向在红冲行上与现金真相相反；而项目名+流量金额的组合在已知的全部明细类表型（丁、戊、清平型、鼎弘型）中语义一致。该决策与"按表型分派处理"的方案相比，新增表型只需扩词典词条，不需改分派代码。

## Consequences

- 新增表型列名叫法时，只需在 `references/字段语义词典.json` 扩词条。
- 项目名为非标准写法（认不出收付方向）时，行为回退到借贷镜像读法，与改动前一致。
- 序时账类（无流量金额列）完全不进入新分支，行为不变。
