# ADR 0012：自动修改最低证据分由客户逐运行选择

- 状态：已采纳
- 日期：2026-08-24

## 背景

四档来源质量和十种合法总分衡量修改主张的证据质量，但客户对自动修改风险的容忍度可以不同。原实现把70和90硬编码为唯一自动修改区间，无法在不改代码的情况下采用更审慎或更积极的口径。

## 决定

每次新运行由客户从50、55、70、90中选择自动修改有效原项目的最低证据分，默认并推荐70。选择值在预检时校验，写入运行状态和运行清单，并由首次分类、全部Agent结果出口和工作簿共同使用。旧运行因版本不一致不得续跑。

该值只授予修改有效原项目的最低分权限，不改变来源评分、十种合法总分、空白原项目补列、内部划转、明确排除、重要性责任和任何强制检查。

## 后果

- 客户可以按项目风险选择同一套可复核的证据门槛；
- 一次运行中只有一个阈值，不允许不同阶段各用一套值；
- 默认70保持既有使用习惯；
- 降低阈值不会跳过M1至M3的复核和人工责任，提高阈值也不会阻断合法补列或内部划转排除。
