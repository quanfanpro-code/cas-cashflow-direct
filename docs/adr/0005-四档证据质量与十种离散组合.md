# 四档证据质量与十种离散组合

状态：已接受；取代 `0001-evidence-scoring.md`、`0003-证据评分矩阵与两类独立来源.md` 以及 `0004-AI依据门禁与冲突分差口径.md` 中按分差认定冲突的部分。

现金流分类只认本行摘要和本行完整对方科目路径两个可能独立的业务证据来源。每个来源按无效0、弱10、中25、强45评质量，两个独立且支持同一候选的来源形成0、10、20、25、35、45、50、55、70、90十种唯一组合；来源冲突时不形成可使用总分，AI轮次、原项目、方向、规则和NOTE均不增加来源或分数。

曾考虑继续修补旧15/30/40/70权重和只按0至2个来源计数。前者无法唯一还原证据组合且多处阈值漂移，后者不能表达来源内部质量；新方案以固定离散组合换取可解释性、单调性和逐格测试能力。

2026-08-24补充决策：每次运行的有效原项目自动修改授权档为45（单强）、50、55、70、90，默认并推荐70。50、55、70、90按总分是否达到所选档判断；45档不是普通数值下限，只在总分为45、55、70或90且至少一个来源质量为45时成立，两个25分形成的纯50分不得借45档自动修改。所有初次分类和Agent结果出口必须调用同一授权函数，冲突、方向、重要性和强制检查继续先行。
