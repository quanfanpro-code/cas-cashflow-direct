# 决策记录0014：低于实际执行重要性的空白原项目采用公开兜底定序

日期：2026-08-26

状态：已采纳

## 决策

原表现金流项目为空、真实现金金额和方向已经确认、经过规定复核仍未形成最终项目，且单笔金额低于本次实际执行重要性时，必须形成具体项目。完整对方科目路径与摘要中分数较高的来源优先；同分时优先完整路径。被选来源有多个候选时按既有候选次序和现金方向选择；两项来源均无候选时，流入落入收到其他与经营活动有关的现金，流出落入支付其他与经营活动有关的现金。摘要或路径非法状态继续留痕，但不阻止本项低金额兜底。

达到实际执行重要性后仍未决的事项进入重要待复核事项，不适用本兜底。

## 原因

低金额未决逐项交给人工会形成大量无法有效处理的事项。公开定序可以稳定形成结果，同时保留不确定性的真实证据边界。

## 后果

兜底不提高证据分数，不伪装两项来源一致，并在全量留痕中记录选中来源和兜底步骤。重要性金额来自每次运行输入，不写死固定金额。
