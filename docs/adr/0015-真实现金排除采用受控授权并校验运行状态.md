# 决策记录0015：真实现金排除采用受控授权并校验运行状态

日期：2026-08-26

状态：已采纳

## 决策

真实现金业务不得凭“无法分类”“不确定”等自由文字排除。允许的排除仅限内部划转、非现金、零金额、现金范围排除、已确认重复和已确认调整；程序必须核验当前业务事实是否满足对应类型。已确认调整还必须记录调整金额、依据和操作人。

每次导入人工决定、导入人工智能结果和最终输出前，运行状态中的正式决定、待处理阶段与SQLite记录必须一致；不一致时停止并报告差异。

## 原因

自由文字排除会让真实现金从正表和勾稽中同时消失，直接修改状态文件还可能绕过正式决定记录，二者都会制造假相符。

## 被否决方案

1. 在普通人工表保留自由排除选项：无法证明真实现金为何可以消失，否决。
2. 只校验`excluded=true`字段：直接修改状态文件即可绕过正式记录，否决。
3. 把排除金额从现金桥接同时删除：会制造假相符，否决。

## 后果

普通人工表只提供具体正表项目，不提供自由排除入口。合法排除和调整仍可通过结构化兼容入口办理，并完整进入桥接和审计留痕。
