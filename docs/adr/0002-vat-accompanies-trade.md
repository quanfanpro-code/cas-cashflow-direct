# ADR 0002：增值税伴随交易归类原则

决策：现金流的进项税、销项税只在同凭证、同现金方向、共用已确认现金来源且只有一个非税基础组成时建立附属关系。价款和税额继续分别保留金额、原基线、摘要、完整路径和来源；基础组成落定项目或明确排除后，税额组成跟随同一决定。基础组成待人工时只允许基础行一次人工选择，税额行使用受保护公式引用，不设置第二个下拉。关系缺失或冲突时不得猜测，也不得仅因金额小强制复核。只有单独向税务机关缴纳增值税才归“支付的各项税费”。附属税额形成原项目差异时，差异表明确列示“随唯一基础项目确定”，评分标记为不适用，不得把附属跟随冒充增值税自身0分自动改判。

背景：此前“对方科目含应交税费”即触发“支付的各项税费”，导致含进项税的服务费被误判为缴税；后续价税拆分又可能让税额组成独立寻找项目并重复送人工。曾考虑在构造阶段合并价税组成和建立通用凭证依赖图，前者会丢失分别填写的原项目和金额来源，后者会让福利费、往来款等非税组成发生候选传染。现方案只增加增值税专属附属关系，复用既有现金来源分配和工作簿金额桥，是满足可追溯与不重复确认的最小改动。
