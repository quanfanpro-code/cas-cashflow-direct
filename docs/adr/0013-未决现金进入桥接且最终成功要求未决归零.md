# 决策记录0013：未决现金进入桥接且最终成功要求未决归零

日期：2026-08-26

状态：已采纳

## 决策

已经确认属于现金范围的真实现金，不因尚未分到具体现金流量表项目而从勾稽中删除。现金变动桥接固定列示已分类净额、尚待分类净额、汇率影响、已确认调整、桥接差异和最终差异。

桥接差异为零但尚待分类现金净额不为零时，状态只能是“现金变动桥接相符、现金流量表尚待分类”。只有尚待分类现金净额为零、必做人工决定完成且最终差异为零，才能写“最终现金流量表勾稽成功”。

## 原因

未决代表分类尚未完成，不代表现金没有发生。把未决金额丢弃会制造虚假的勾稽差异，或在反向调整后制造虚假的相符。

## 后果

人工决定只把金额从尚待分类转入具体项目，现金变动总额在转移前后保持不变。任何排除和调整必须单独披露并可追溯。
