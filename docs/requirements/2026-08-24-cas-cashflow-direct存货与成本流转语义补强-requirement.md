## 一、背景与问题

“最终结转至主营业务成本”只能说明成本的最终去向，不能单独证明本次现金支付属于购买商品、接受劳务。现行程序已经能够区分部分材料、人工和非现金成本，但完整路径覆盖仍有共同缺口：

1. `生产成本_外协加工费`、`合同履约成本_材料费`等路径只形成部分解释，不能形成正确候选；
2. 存货科目只零散覆盖原材料、库存商品等词，没有区分外购入口、成本归集、内部流转和最终结转；
3. 制造费用、劳务成本、合同履约成本、主营业务成本和其他业务成本的父级语境不够准确，可能把生产投入误当普通经营费用，或因为证据不足制造人工复核；
4. 发出商品、完工入库、领用、分配、折旧、摊销、减值和成本结转等非现金流转必须与真实外购付款严格分开。

## 二、用户与使用场景

面向使用一般企业直接法现金流量表Skill的财务和审计人员。程序读取真实现金业务组成中的本行摘要和完整对方科目路径，判断本次现金实际购买的商品、材料、服务或其他业务性质。人工不应仅因相关支出最终进入主营业务成本而批量改变原项目，也不应因程序漏识别常见存货和成本路径而承担不必要复核。

## 三、功能范围

### 3.1 建立一条受控的存货与成本流转语义链

程序必须能够解释下列关系，但现金流分类始终锚定本次现金实际支付内容：

`外购商品、材料或外部生产服务 → 存货入口 → 成本归集 → 产品或履约成本 → 主营业务成本或其他业务成本`

链条只用于保留业务性质，不得根据后端科目反向证明前端发生了外购现金支付。

### 3.2 存货与成本节点范围

1. **外购入口**：材料采购、在途物资、原材料、外购库存商品、委托加工物资、周转材料、包装物、低值易耗品，以及明确为外购的半成品、产成品或商品采购；
2. **存货状态或内部流转**：库存商品、发出商品、在产品、产成品、半成品、材料成本差异、商品进销差价；这些节点本身不直接证明外购；
3. **成本归集**：生产成本、制造费用、劳务成本、合同履约成本；
4. **最终成本去向**：主营业务成本、其他业务成本；这些节点本身最多形成宽泛成本性质，不直接决定现金流项目；
5. **非现金调整**：存货跌价准备、合同履约成本减值准备，以及计提、减值、转销、领用、分配、入库、完工、结转、摊销、折旧等关系。

### 3.3 按本次支付对象分类

1. 完整路径明确为外购材料、商品、委托加工、外协加工、外部生产服务、生产用水电燃料或直接履约服务时，形成“购买商品、接受劳务支付的现金”候选；
2. 路径明确为本企业职工工资、薪酬、社保、福利或其他职工支出时，形成“支付给职工以及为职工支付的现金”候选；
3. 路径明确为税费、长期资产、借款、投资或其他已存在的特殊性质时，继续由对应专用规则处理；
4. 管理、销售和普通经营费用继续形成“支付其他与经营活动有关的现金”候选；
5. 差旅费、交通费、住宿费等仅凭进入合同履约成本或主营业务成本，不能自动视为购买商品、接受劳务。只有摘要或路径进一步明确外部履约服务对象时才能改变；
6. 存在非现金流转标记时，完整路径不得形成现金流候选；现金业务仍可由独立摘要证据判断，但不得把非现金路径加分。

### 3.4 路径证据质量

1. 完整路径同时明确链条位置、外购对象或外部服务性质，候选唯一、节点完整且没有冲突时，可以形成45分强路径证据；
2. 只有“存货”“生产成本”“合同履约成本”“主营业务成本”等宽泛节点时，最多形成10分弱证据，不得自动改判；
3. 路径存在未识别节点但仍能唯一指向候选时，按现有规则最高25分；
4. 职工、税费、长期资产或非现金关系与外购候选冲突时，不得忽略相反证据；来源冲突没有可用总分；
5. 摘要和路径仍是两个独立来源，评分方法、自动修改最低分和重要性行动表不变。

### 3.5 人工复核与金额桥

1. 达到整体重要性的单笔继续进入人工确认，不因本次语义补强绕过门禁；
2. 人工选择只进入人工调整和最终金额，不反写自动基线、证据分数或固定规则；
3. 本次规则补强只减少因为路径漏识别产生的不必要人工事项，不负责证明所有原项目正确；
4. 不能根据历史人工选择、客户名称、金额、凭证号或来源行生成特例。

## 四、明确不做

1. 不建设跨期间、跨凭证、逐批存货的购入—领用—完工—销售追踪系统；
2. 不根据主营业务成本、其他业务成本或存货科目余额倒推现金流项目；
3. 不把发出商品、库存商品、合同履约成本等单一科目直接绑定某一现金流项目；
4. 不改变评分中心、行动表、重要性分层、45/50/55/70/90最低分选择、增值税附属继承或工作簿结构；
5. 不新增大模型调用、依赖、工作表或第二套语义引擎；
6. 不扩展金融企业、房地产、农业等行业专用现金流规则。行业专用科目可保留为中性或未识别节点，但不得在本轮猜测专用分类。

## 五、约束与风险

1. `库存商品`既可能来自外购，也可能来自自产完工，必须结合外购词、成本明细和非现金标记；
2. `合同履约成本_差旅费`可能是员工报销，也可能是外部履约服务，不能仅凭最终结转成本决定；
3. 生产维修、检测、运输和水电等只有在父级语境明确为生产投入时才形成购买商品、接受劳务候选；管理或销售语境仍归其他经营支出；
4. 非现金阻断规则必须优先于材料、设备、人工等普通词，防止结转、折旧和减值被误判为现金流；
5. 完整路径的每个节点继续必须有直接识别、父属性继承、中性限定或明确未识别的去向。

## 六、验收标准

### 6.1 正向路径

下列构造路径必须形成“购买商品、接受劳务支付的现金”唯一候选且路径质量为45分：

1. `材料采购_直接材料`；
2. `在途物资_商品采购`；
3. `原材料_钢材`；
4. `委托加工物资_加工费`；
5. `周转材料_包装物采购`；
6. `生产成本_外协加工费`；
7. `制造费用_生产用电费`；
8. `劳务成本_外部劳务费`；
9. `合同履约成本_外部履约服务费`；
10. `主营业务成本_外包服务费`。

### 6.2 覆盖与阻断路径

1. `生产成本_人工_福利`仍唯一指向职工现金流项目；
2. `生产成本_设备折旧`、`周转材料_摊销`、`库存商品_完工结转`、`发出商品_结转主营业务成本`、`存货跌价准备_计提减值`均不形成现金流候选；
3. `合同履约成本_差旅费`不得仅凭路径形成购买商品、接受劳务候选；
4. `主营业务成本`、`库存商品`等单一宽泛路径不得取得45分；
5. 管理费用下的办公水电、维修和差旅不得被生产投入规则覆盖；
6. 每条路径的所有节点都有明确解释去向，没有静默丢失。

### 6.3 行为和验证

1. 先以构造测试证明现行规则失败，再最小修改共同词典和路径规则；
2. 定向测试、受影响测试和普通全量回归全部通过；
3. 第五阶段只执行一次真实样本冒烟，比较规则补强前后候选、分数、自动修改和待人工数量；不得以减少人工数量作为强行归类目标；
4. 不重复十万行性能测试，不调用LM Studio或其他模型服务；
5. Skill结构校验、Python编译、编码异常字符扫描和`git diff --check`通过；
6. README现行说明和Changelog、SKILL、CONTEXT、权威设计、实施计划及复核记录保持一致。
