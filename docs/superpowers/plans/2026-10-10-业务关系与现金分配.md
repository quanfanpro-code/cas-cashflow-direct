- 全程以整数分计算，保持现金逐来源的流入、流出和未决余额守恒。

- 原现流项目不作为关联或分类证据。
- 净额零、同摘要、金额一致、行数最少均不能单独证明业务关系。
- 原始工作簿及现有规范化副本只读；旧运行不迁移、不覆盖；规则变化后新建运行。

## 任务1：定义结构事实及完整方案的校验契约

文件：`models.py`、新增 `component_structure.py`、新增 `tests/test_business_structure.py`、`rule_registry.py`、特殊业务规则JSON。

生产数据契约使用只读dataclass；嵌套列表用tuple，运行状态序列化时沿用 `asdict`。结构标识由原始行身份、方案内容和规则版本形成稳定ID，不依赖输入排序。

```python
@dataclass(frozen=True, slots=True)
class StructureEvidence:
    entry_id: str
    start: int
    end: int
    text: str
    relation: str

@dataclass(frozen=True, slots=True)
class StructureCashShare:
    entry_id: str
    amount_cent: int

@dataclass(frozen=True, slots=True)
class StructureBusinessGroup:
    group_id: str
    main_entry_ids: tuple[str, ...]
    settlement_entry_ids: tuple[str, ...]
    cash_shares: tuple[StructureCashShare, ...]
    evidence: tuple[StructureEvidence, ...]
    path_depends_on_summary: bool = False

@dataclass(frozen=True, slots=True)
class StructureNonCashGroup:
    group_id: str
    entry_ids: tuple[str, ...]
    evidence: tuple[StructureEvidence, ...]

@dataclass(frozen=True, slots=True)
class VoucherStructurePlan:
    plan_id: str
    voucher_key: str
    business_groups: tuple[StructureBusinessGroup, ...]
    noncash_groups: tuple[StructureNonCashGroup, ...]
    unresolved_entry_ids: tuple[str, ...]
    pending_cash_shares: tuple[StructureCashShare, ...]

@dataclass(frozen=True, slots=True)
class StructureSearchResult:
    plans: tuple[VoucherStructurePlan, ...]
    search_complete: bool
    reason: str
```
