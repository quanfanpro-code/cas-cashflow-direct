# cas-cashflow-direct 存货与成本流转语义补强设计

## 一、设计目标

补齐存货入口、成本归集、内部流转和最终营业成本路径，使程序依据本次现金实际支付对象分类，而不是根据“最终结转主营业务成本”倒推。实现必须复用现有完整路径语义中心、固定质量计算和统一行动中心，不新增分类框架。

## 二、方案比较

### 方案A：按最终成本科目统一分类

只要路径进入存货、生产成本或主营业务成本，就统一形成“购买商品、接受劳务支付的现金”。

- 优点：实现最少，人工事项下降快；
- 缺点：会把职工薪酬、折旧、摊销、结转、减值和普通费用全部误判，重新制造“根据最终去向证明本次付款性质”的错误举证责任；
- 结论：不采用。

### 方案B：跨凭证追踪每批存货和成本流转

连接采购、入库、领用、生产、完工和结转凭证，追踪每笔现金最后进入哪个成本项目。

- 优点：理论上可以形成更长的成本来源链；
- 缺点：需要存货明细账、成本核算对象、批次或项目辅助核算和跨期匹配，数据要求远超当前五类输入；实现和验证成本高，仍不能仅凭最终成本去向决定现金流项目；
- 结论：本轮不做。

### 方案C：扩充现有完整路径关系规则

将存货与成本节点分成外购入口、存货状态、成本归集、最终成本去向和非现金流转五类；固定程序按父级语境和末级业务对象组合候选。

- 优点：复用现有JSON词典、完整路径规则、非现金优先阻断和质量计算；不新增依赖；能够覆盖共同根因；
- 缺点：语义不足的路径仍会保留弱证据或人工出口；
- 结论：推荐并采用。

## 三、领域模型

### 3.1 成本流转链

成本流转链表示同一业务性质可能经过外购入口、存货、成本归集和营业成本等不同会计位置。它只解释路径上下文，不是跨凭证追踪结果，也不是现金流项目证据本身。

### 3.2 五类节点

1. **外购入口**：材料采购、在途物资、原材料、明确外购的库存商品、委托加工物资、周转材料、包装物、低值易耗品；
2. **存货状态**：库存商品、发出商品、在产品、半成品、产成品、商品进销差价、材料成本差异；
3. **成本归集**：生产成本、制造费用、劳务成本、合同履约成本；
4. **最终成本去向**：主营业务成本、其他业务成本；
5. **非现金流转**：领用、分配、入库、完工、结转、转销、计提、减值、摊销、折旧。

### 3.3 业务对象

路径节点只有与以下业务对象组合后才形成候选：

- 外购商品或材料；
- 外协、委外加工或外部生产服务；
- 生产用水电、燃料、检测等直接生产投入；
- 客户项目的外部履约服务；
- 职工薪酬、税费、长期资产等既有特殊对象；
- 管理、销售或普通经营费用。

## 四、规则优先顺序

固定程序按以下顺序解释完整路径：

1. **非现金优先阻断**：只要路径命中结转、领用、入库、分配、折旧、摊销、减值等关系，路径不形成现金流候选；
2. **特殊性质优先**：职工薪酬、税费、长期资产、投资、借款等沿用现有专用规则，不能被成本父级覆盖；
3. **外购入口**：现金业务的完整路径明确为材料采购、在途物资、原材料或其他外购存货时，形成购买商品候选；
4. **成本归集和最终去向**：生产成本、制造费用、劳务成本、合同履约成本、主营业务成本或其他业务成本必须再结合末级明细；材料、外协、直接生产投入或外部履约服务形成购买商品、接受劳务候选；
5. **普通经营费用**：管理、销售等父级下的普通费用仍形成支付其他经营现金候选；
6. **不足或冲突**：父级或末级不足以唯一判断时保留弱证据或未识别；来源冲突没有可用总分。

## 五、数据流

`现金业务组成 → 完整路径分层 → 节点概念识别 → 非现金和特殊性质检查 → 父级语境＋末级对象组合 → 路径候选和质量 → 摘要独立判断 → 现有评分中心 → 现有行动中心`

本轮不改变任何下游接口。`account_dictionary.py`继续读取同一个`科目语义词典.json`；`classification.py`继续把摘要和路径作为两个来源；`decision_policy.py`继续决定自动保持、自动修改、复核或人工。

## 六、最小实现

### 6.1 词典概念

在现有概念表中补充：

1. 外购存货入口词族；
2. 存货状态和成本最终去向词族；
3. 外部生产服务、直接生产投入和外部履约服务词族；
4. 领用、分配、入库、完工等非现金流转词族；
5. 存货减值和合同履约成本减值词族。

单个词条仍不得携带现金流项目或质量。

### 6.2 完整路径规则

优先复用现有规则结构，只增加或扩充以下共同规则：

1. 外购存货入口＋非现金禁用；
2. 成本归集或营业成本父级＋材料采购对象；
3. 成本归集或营业成本父级＋外部生产或履约服务；
4. 成本归集父级＋生产用水电燃料和直接检测投入；
5. 非现金流转停止规则扩展。

不新增Python判断分支。除非测试证明现有规则表达能力不足，否则不修改`account_dictionary.py`。

## 七、证据质量

1. 完整路径节点全部解释、候选唯一、外购或外部服务关系明确且无冲突时为45分；
2. 只有成本父级或存货状态时为10分，不形成唯一候选；
3. 有未识别节点但候选仍唯一时最高25分；
4. 非现金停止规则命中时没有路径候选；路径概念可以保留为10分解释留痕，但不得加入现金流项目分数；
5. 摘要和路径相互冲突时沿用现有来源冲突出口。

## 八、错误处理和边界

1. `库存商品`单独出现时不区分外购商品和自产完工，不形成45分；
2. `发出商品`、`产成品`、`主营业务成本`单独出现时只说明状态或去向，不形成购买商品候选；
3. `合同履约成本_差旅费`保留歧义；摘要明确员工报销时归其他经营支出，明确外部履约服务时才形成购买商品、接受劳务候选；
4. 自定义行业科目无法由通用词族解释时继续进入现有受控节点补充，不写企业特例；
5. 词典哈希变化自动使旧运行拒绝续接，不修改运行结构和评分版本。
